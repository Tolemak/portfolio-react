# portfolio-react

Moja strona, [kamil-galkowski.pl](https://kamil-galkowski.pl). React + TypeScript + Vite, strona główna w 3D (react-three-fiber) z wersją klasyczną obok, PL/EN, jasny i ciemny motyw.

[English version](README.md)

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run lint
npm run build
```

CI wrzuca zbudowany `dist/` na gałąź `build`, z której deployuje serwer.
