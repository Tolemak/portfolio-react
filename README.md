# portfolio-react

My portfolio site, [kamil-galkowski.pl](https://kamil-galkowski.pl). React + TypeScript + Vite, a 3D home page (react-three-fiber) with a classic one next to it, PL/EN, light and dark theme.

[Polska wersja](README.pl.md)

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run lint
npm run build
```

CI pushes the built `dist/` to the `build` branch, the server deploys from there.
